# AUDIT_06: citation audit of the section (c) synthesis in facet K

**Date:** 2026-10-13. **Auditor:** independent (did not write facet K). **Nothing in the facet, the .bib or elsewhere has been changed.** This is the only file I wrote.

**Scope.** `literature/facets/K_training_and_cause.md`, `## (c) Synthesis` (lines 282-358, through "Claims the sources contradict or qualify") up to the start of `## (d)` (line 361), plus `K_training_and_cause.bib` (all 36 entries; metadata checked for every entry cited in (c), DOIs checked for all 13). Section (b) (lines 57-280) read only to see what the agent says it read, and to find the snippet it joined.

**Checks run.**
1. **Continuity test on the archive.org lending scans.** The full-text API (`be-api.us.archive.org/fts/v1/search?q=...&identifier=<item>`) matches an exact phrase only if the words are adjacent in the OCR text (line-end hyphens and `¬` are kept as printed, so I typed them). So I ran each quotation, and each join the facet made, as one long phrase query. A hit on the whole phrase means the words are one continuous passage. Control: `"Word separation, the diastole, the hyphen, and shortcuts"` (a deliberate stitch) returned 0 hits, while the real sentence returned 1. Where a quotation failed as one phrase I tried it in halves. To read context I extended a phrase forward and backward and re-validated every extension as a single phrase, because my first, unvalidated extension of the Cavallo and Chartier passage produced a false join (discarded).
2. **Google Books search-inside** (`books.google.com/books?id=<id>&jscmd=SearchWithinVolume2`), which returns the printed page. It returned results only for short queries and was erratic; I use it only for page numbers. IDs: Saenger 1997 `w3vZaFoaa3EC`; Johnson 2010 `45eXJSpxdn4C`; Cribiore 1996 `NQwcAQAAIAAJ`. The Google Books API itself was quota-blocked (429).
3. **Open full text:** Quintilian 1.1 and 1.8 (Butler's Loeb, Penelope/LacusCurtius, three pages fetched); Roberts's 1910 Dionysius and Davidson's 1874 Thrax (archive.org `_djvu.txt`, public domain). Perseus's Greek and Usher's Loeb were not consulted.
4. **Zero-hit re-run** for eight "silent" books with 20 term variants each (table below).
5. **Crossref** record for all 13 DOIs in the .bib (title, type, container, volume, pages, issued date, authors); archive.org metadata for publisher and year of eleven scans.
6. Each quotation read against the claim hung on it.

**Result in one line.** The quotation wording is mostly real. Most of the joined snippets the agent worried about turn out to be continuous text (Marrou, Johnson, Baron, Parkes, Richter, the Cavallo and Chartier lines). The errors are elsewhere: a Japanese passage presented as Western pre-separation teaching, two quotations and a "line and page" passage credited to the wrong author, a Baron scribe-nation reversed, a Cribiore sentence whose next sentence says the opposite of how it is used, and several verdicts that rest on a reviewer word used for a different claim.

**Counts.** WRONG 4. OVERSTATED 18. STITCHED 2. UNCHECKABLE 2. (VERIFIED rows, verbatim or paraphrase: 20.)

**Status key.** VERIFIED verbatim (continuous text seen) / VERIFIED paraphrase / STITCHED / OVERSTATED / WRONG / UNCHECKABLE.
